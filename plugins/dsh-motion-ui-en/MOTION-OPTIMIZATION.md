# 动态交互优化目标（0.6.0 本地开发批次）

1. 原生控件：分段选择器、滑块填充、开关和复制反馈；真实状态驱动，键盘可用，不模拟工具成功。
2. 数据过渡：数值即时保持精确，关联进度/柱形平滑过渡；首次加载、只读预览和 reduced motion 不播放交互动画。
3. 动态案例：本地按需目录及少量完整案例，注入简短选择指引；不整库注入，不要求读安装源码。
4. 风格：新增「柔光渐彩」，实色表面、浅彩渐变、圆润按钮、柔和阴影；无玻璃、无持续漂浮，提供五种布局预览及模型示例。
5. 验证交付：PC 明暗主题、键盘、快速连续操作、状态恢复、复制失败与减少动态效果；完整回归后替换 Desktop/Web，暂不发布。

参考：Lucian UX/UI Prompt 的交互反馈、主题 token 与按需案例组织。实现使用 Motion UI 自有组件和共享状态，不移植演示用计时进度、假成功或玻璃材质。
