# 动效与视频开发目标

顺序：动效指导 → 按需案例 → 可定位时间轴/分步讲解 → 录屏分析 → 视频制作、处理与导出。

- 保留六种视觉风格、自由模式、原生 UI 和现有 DSHUI.animate；自由模式只增加接口，不强加动效美术指导。
- 案例采用原创小例子，按需读取，隔离多实例，不把上游整套技能注入每次请求。
- 时间轴用绝对秒数绘制，支持定位、暂停、重播、章节、减少动态效果和离屏暂停；不逐帧写入持久状态。
- 视频以可编辑源码为主，MP4 为派生产物。检查实际编解码结果，失败保留源码，不假报交付。
- 支持检查本地视频、按时间抽帧、基础剪辑与音轨/字幕合成。抽帧不是语音识别或完整语义理解。
- 本地无头浏览器、FFmpeg、FFprobe 按能力检测；缺失时给出明确错误，不偷偷安装大型运行时。
- 不改变模型推理/输出/时间设置；真实模型测试仅用“测试结果”工作区。
- 开发验证通过后替换 Desktop 供用户测试；本轮未授权发布，不创建 Release 或推 npm。

## 0.8.0 宣传片端到端验收

- 新增按需宣传片制作指导，模型从功能简报组织文案、不同构图的分镜、动画与交付检查。
- `synthesize_voice` 使用显式配置的 mmx/MiniMax 认证，返回真实音频及句级/词级时间戳，不复制 DSH 模型密钥。
- `audioTracks` 支持配音、音乐、音效混合、偏移、音量和淡入淡出；旁白不能循环或被片长截断。
- 可编辑工程 ZIP 包含 HTML、文档、音轨、字幕与参数；独立预览字幕在空档消失。逐帧直接送入 FFmpeg，不堆积 PNG。
- 实测发现并修复可选 JSON 空字符串兼容、服务段落字幕拆分和数值多个发音片段重复原文的问题，使用真实词时间与原文位置，不插值。
- M3.1 Flash Preview High 已根据需求制作 Motion UI 0.8.0 宣传片，保留首轮及返修过程中的失败证据，不改模型推理/输出限制。
