# 0.5 系列发布候选范围

日期：2026-10-09。开发基线 0.5.1；整批验收完成后统一交付一个补丁版本。本文定义开发与安装验收，不授权 npm/GitHub 外部发布。

## 目标与来源

让模型在 DSH 原生会话中自由创作可交互 HTML/SVG 动画，并与标准数据组件组合；保持可恢复、可解释、可访问的交互体验。

- [OpenUI](https://github.com/thesysdev/openui)：采用组件目录与能力说明共享来源的思想；本轮不替换 DSH 聊天或引入未实测的 React 语言运行时。
- [Diagram Design](https://github.com/cathrynlavery/diagram-design)：按关系选择流程、层级、时序等表达，处理节点标签和连线空间；通过画布创作，不限制为一套预制图形。
- [Taste Skill](https://github.com/leonxlnx/taste-skill)：提炼视觉层级、留白与情境审查；其营销页面默认规则不直接用于数据工具。
- [Thesys 逆向观察](https://www.openui.com/blog/how-chatgpt-intelligent-ui-works)：借鉴局部状态、稳定身份与隔离执行的方向。它是第三方观察，不是 OpenAI 官方协议；本插件不宣称复刻私有编译器。

| 跨场景设计 | 提供工程拆解、参数实验、关系结构、数据分析、方案比较、阅读说明的设计简报；新增至少两种不同构图的可运行示例 |
| 使用体验 | 明确的加载状态；正常时收起辅助操作；异常时提供恢复入口和文字说明；调试细节默认折叠 |
| 动画生命周期 | 提供可清理的动画辅助接口，后台/离屏暂停、减少动态效果静态回退；重置和停止销毁旧运行实例 |

| 流式稳定 | 完整有效子树预览；预览不执行脚本；参数更新保持 iframe 身份；提交成功并恢复参数后才执行 |

| 视觉验收 | 新示例与既有场景覆盖浅/深主题、390px/768px/桌面，中文长文、键盘操作、减少动态效果、文字替代 |
| 交付与兼容 | 构建、检查、打包、安装文件哈希、DSH Web 配置、真实会话回放通过；记录包版本、构建标识、已知限制；Desktop 不变 |

## 明确的边界

没有 CPU/内存硬隔离；自导航不是完整网络防火墙。外部资源、任意工具桥、复杂物理精度保证、OpenAI 私有协议兼容、OpenUI DSL 全量适配、任意运行中代码补丁不属于本轮发布门槛。动画时间可以重置，重要参数必须持久化到 document.state。

0.5.2 候选开发与验收通过。仅统一升级一个补丁版本，没有逐项功能升版本。

最终安装包及构建标识以安装后的 `test-output/release-verification.json` 与交付记录为准；这些自动生成证据不随 npm 包发布。没有执行 npm/GitHub 外部发布。
