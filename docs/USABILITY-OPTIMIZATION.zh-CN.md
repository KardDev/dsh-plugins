# Motion UI 易用性与编辑优化

2026-10-14；本轮版本保持 0.7.0，未发布。最终构建 0.7.0+9069fca0d517。

## 顺序目标与完成标准

| 顺序 | 目标 | 完成内容与验收 |
|---|---|---|
| 1 | 接口兼容与精确诊断 | code.copyable:true、单一数值 expr、与 state 一致的控件范围、flow 布局明确兼容；冲突仍拒绝；图表缺 rows 和嵌套公式标明字段路径。不补猜数据、不改任意数据或源码。 |
| 2 | 常见需求短入口 | 新增 render_scene 的 flow/comparison/allocation/budget，生成完整节点、公式和控件；缺数据明确拒绝。原生/自由入口保留，同轮多文档、只读预览、样式与保存复用。 |
| 3 | 轻量视觉检查 | 透明背景颜色合成、裁切与尾部空白；返回局部 selector/文字/tag。最多2000元素、40问题，祖先扫描受限；截断不推断空白。渐变、SVG配色等未覆盖不标通过。 |
| 4 | 定位与局部修改 | inspect_ui query 检索文本/标签/类型，返回父节点、位置、路径和可编辑字段；复用原版本校验与 patch/update。浏览器及模型验证改原文档、保留人数5和预算9400，刷新有效。 |
| 5 | 固定真实模型回归 | scripts/verify-model-usability.mjs，显式设置私有登录日志/URL，限定测试工作区；不新增推理/输出/时间限制、不取消模型；保存实际工具调用、错误、首块可见时间和修改结果。 |

## 验证

- 129 项单元/集成测试通过；24 组完整回归通过。最后补充的「截断不误判空白」定向浏览器验证也通过。
- 1920、1365和390宽度验证四类场景；透明色对比度、裁切和空白有正反例，滚动区域不会当裁切。
- 实际模型 MiniMax-M3.1-Flash-Preview High，测试结果工作区；本轮最终固定用例4/4通过，无工具错误、无浏览器异常。单轮样本不是稳定性或成功率保证。

| 固定场景 | 总回复耗时 | 首块可见 | 实际调用 |
|---|---:|---:|---|
| plain-fact | 3.3秒 | 不适用 | 纯文字 |
| proactive-flow | 11.4秒 | 6.7秒 | render_scene |
| multiple-and-budget | 9.4秒 | 5.7秒 | render_scene → render_scene |
| targeted-followup | 7.4秒 | 不适用 | inspect_ui → patch_ui |

首块可见为500ms间隔的桌面DOM观察值，包含本次请求环境的影响；不能当模型速度基准或跨模型性能结论。实际推理及输出配置沿用用户已有值，没有改写。

初轮记录保留：五步流程曾选择普通文字，随后曾为文案修改生成两份同名UI。调整表达目标的指导和工具成功回执后，回归明确要求「一个流程只交付一份」，最终通过。首次跟进用例的脚本曾误以为每轮都会重复 request/header；改为读取本会话最后有效配置后验证，不把脚本误判记作插件错误。

## 本地与复现

Desktop/Web 通过本地打包文件比对与运行中 Host/Client 构建核验；不改变用户风格偏好。模型回归恢复原模式和风格。项目中历史审计报告保留上一轮口径，本报告是本轮新增能力的记录。

- 自动回归：DSH_PLAYWRIGHT 指向 Playwright 模块后，node scripts/verify-release.mjs。
- 真实模型：设置 MOTION_WEB_LOG（私有登录日志）或 MOTION_TEST_URL；默认 M3.1 Flash、测试结果工作区，MOTION_WORKSPACE_DIR 指定对应目录，然后 node scripts/verify-model-usability.mjs。
- 报告与截图保存在 test-output/usability-*；不会将鉴权URL写入结果。
